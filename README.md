# 兒童書寫練習產生器 V2.4.4｜ZIP完整備份版

## V2.4.4 主要更新

- 完整家庭備份改為單一 ZIP 檔。
- `backup.json` 僅保存學習資料與圖片索引。
- 自訂水果照片保存於 `fruit-photos/`。
- 手寫作品保存於 `artworks/`。
- 數學暫存圖片保存於 `math-drafts/`。
- 圖片不再以 Base64 塞入 JSON，因此備份容量更小、更容易檢查。
- 匯入 ZIP 時會驗證目錄、CRC、檔案數、容量、圖片類型與照片引用完整性。
- 保留 V2.4.3 與較舊 JSON 備份匯入相容性。
- 完全在瀏覽器本機處理，不會把照片或備份傳到 GitHub 或任何伺服器。

## GitHub Pages

將此資料夾內檔案直接覆蓋上傳到 Repository 根目錄即可。

> 完整家庭備份可能包含小朋友名稱、手寫作品與自訂照片，請勿上傳到公開 Repository。
